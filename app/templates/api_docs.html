Webhook

Method Endpoint Description
POST /webhook Receives GitLab merge request webhook events. Triggers an AI code review.
POST /webhook — Details

Headers

Header Required Description
X-Gitlab-Token If GITLAB_WEBHOOK_SECRET is set Must match the configured webhook secret
X-Gitlab-Event No Event type (logged for debugging)

Accepted events

  • object_kind: "merge_request" with action open, reopen, or update (with new commits)

Response

{"queued": true, "project_id": 35, "mr_iid": 12}

The review runs asynchronously in the background. Results are posted directly to the MR as a comment.

Reviews

Method Endpoint Description
GET /reviews List stored code reviews with optional filters.
GET /reviews — Query parameters
Parameter Type Default Description
project_id int — Filter by GitLab project ID
mr_iid int — Filter by merge request IID
limit int 50 Max results (max 200)

Admin UI — Authentication

Method Endpoint Description
GET /code-review-bot/login Login page. Redirects to dashboard if already authenticated.
POST /code-review-bot/login Submits the admin password and, on success, sets a session cookie.
POST /code-review-bot/logout Clears the session cookie and redirects to the login page.

Admin UI — Protected pages

Method Endpoint Description
GET /code-review-bot/ Admin dashboard
GET /code-review-bot/reviews Review history with search and filters
GET /code-review-bot/webhooks Google Chat webhook management
GET /code-review-bot/health System health dashboard

All protected pages require GitLab OAuth authentication. Unauthenticated requests are redirected to /code-review-bot/login.

Try it

Test the API directly from your terminal:

# Liveness check
curl http://localhost:8888/health

# Full system status
curl http://localhost:8888/health/full | python3 -m json.tool

# List recent reviews
curl "http://localhost:8888/reviews?limit=5"

# Filter by project
curl "http://localhost:8888/reviews?project_id=35&mr_iid=3"
